# Supervised grouped cross-validation 1.0

Изолированный эксперимент по обучению второго семантического слоя. Он не
импортируется в `social_monitor.py`, не изменяет отчёт, state, cache, источники
или рассылку.

Данные — 240 окончательно размеченных карточек. Оценка группируется по
`event_id`: две перепечатки одного сюжета не могут оказаться одновременно в
обучении и проверке. Для каждой из пяти внешних частей модель обучается на
остальных карточках. Порог veto/rescue для этой части выбирается только по
OOF-прогнозам и меткам остальных четырёх частей. Это защищает от утечки и при
обучении, и при настройке порога.

Сравниваются заранее зафиксированные варианты:

1. TF-IDF word+character + LogisticRegression — прозрачная компактная база;
2. SetFit на `intfloat/multilingual-e5-small` — компактный многоязычный
   эмбеддинговый кандидат.

Результат не является основанием включать модель в мониторинг. Даже при
прохождении ворот следующий этап — новая, ранее не использованная
перспективная выборка и теневой запуск.

# S-monitor — компактный SetFit-пилот 1.0

Это отдельный ручной эксперимент. Он **не подключён** к рабочему
`social_monitor.py`, не запускается по расписанию и не читает/не изменяет
`state.json`, `discovery_cache.json`, секреты, email или рабочие отчёты.

## Что установлено в пакете

- event-safe обучающая выборка: 375 SILVER-строк, 297 событий;
- event-safe validation: 62 SILVER-строки, 50 событий;
- закрытый тест: 72 GOLD-строки, 54 события;
- контроль SHA-256 и запрет пересечения событий между split;
- компактный энкодер `cointegrated/rubert-tiny2` (веса не лежат в репозитории);
- ручной workflow без schedule и без постоянного Hugging Face cache;
- контрольный TF-IDF baseline и его зафиксированные результаты.

## Почему GOLD закрыт до конца обучения

Модель и порог выбираются только по SILVER train/validation. GOLD test читается
один раз после фиксации модели и порога. Иначе оценка станет частью настройки и
перестанет быть независимой.

## Как запустить

Содержимое пакета копируется в корень S-monitor с сохранением путей. Новые пути:

1. `.github/workflows/social-setfit-pilot.yml`
2. `ml/setfit_pilot/`
3. `data/ml/event_safe_v1/`
4. `control_baseline/`

Никакие существующие файлы заменять не требуется. После commit:

1. открыть **Actions**;
2. выбрать **S-monitor SetFit pilot (manual, isolated)**;
3. нажать **Run workflow**;
4. после завершения скачать artifact `s-monitor-setfit-pilot-results`.

Запуск может использовать до 60 GitHub Actions minutes, но обычно должен
закончиться раньше. Он выполняется только вручную. Кэш модели не сохраняется, а
artifact хранится 14 дней.

## Критерии первого допуска

В `setfit_metrics.json` решение `SHADOW_CANDIDATE` выдаётся только если на
event-level GOLD test одновременно достигнуты:

- KEEP recall ≥ 0,90;
- KEEP precision ≥ 0,65;
- KEEP F1 ≥ 0,75;
- balanced accuracy ≥ 0,75.

Даже `SHADOW_CANDIDATE` не разрешает заменять фильтры. Это только основание для
следующего этапа: теневые прогнозы на новых плановых запусках без влияния на
пользовательский отчёт.

## Откат

Удалить четыре новых пути из списка выше. Рабочая архитектура S-monitor от них
не зависит.

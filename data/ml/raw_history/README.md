# Сырой архив классификационных решений

Начиная с update75 (2026-09-03), каждый плановый, не dry-run, запуск
архивирует классификационный вывод в этой директории до истечения срока
хранения GitHub Actions artifacts. Update77 добавляет отдельный полный
контракт входа для будущего семантического второго слоя.

- `articles/run-<N>_social_articles_<YYYY-MM-DD>.csv` — включённые (`KEEP`)
  кандидаты и их классификационные признаки.
- `rejected/run-<N>_rejected_signals_<YYYY-MM-DD>.csv` — отклонённые
  (`REJECT`) кандидаты с сильным предфильтром и причина решения; это прежний
  узкий операторский debug-контракт, его смысл не изменён.
- `semantic_inputs/run-<N>_semantic_training_signals_<YYYY-MM-DD>.csv` — все
  кандидаты, для которых после успешного извлечения текста состоялось regex-
  решение релевантности (`KEEP` либо `REJECT`), включая слабые и пограничные
  отказы. Здесь сохраняется нормализованный вход `TITLE/SUMMARY/TEXT`, его
  SHA-256, версия контракта и технические признаки решения.

Префикс `run-<N>` предотвращает перезапись при нескольких запусках в один
день. Во время dry-run архив не создаётся: такой прогон не должен менять
репозиторий.

Это сырой материал SILVER-уровня, а не готовый GOLD-набор. Метки получены
тем же правиловым классификатором, который проверяется, поэтому для обучения
или независимой оценки требуется случайная ручная разметка и event-safe
разделение без попадания одного события в разные выборки.

`semantic_model_text` ограничен 8000 символами, чтобы архив не рос
неограниченно. Хеш считается по полному нормализованному входу до усечения.
Файлы `semantic_inputs/` внутренние: их нельзя включать в публичный отчёт или
публичный артефакт, поскольку они содержат фрагменты извлечённого текста.

Семантический слой проектируется как дополнение к regex-базе, а не замена:

- `veto`: проверяет только regex-`KEEP` и может убрать вероятный шум;
- `rescue`: проверяет только regex-`REJECT` и может вернуть вероятный пропуск;
- для двух маршрутов обучаются и калибруются независимые пороги;
- до прохождения проспективного blind GOLD оба маршрута работают только в
  shadow-режиме и не меняют отчёт.

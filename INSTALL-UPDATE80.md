# Установка update80

Пакет является корневым overlay для репозитория, в котором уже установлен
update79. Содержимое ZIP начинается от корня проекта: создавать вложенную папку
не нужно.

## Что будет заменено или добавлено

- `social_monitor.py` — защищённые профили полноты, политический барьер,
  география событий и дедупликация;
- тесты update77–update79 — только актуальные маркеры сборки;
- `tests/test_update80_run43_precision_recall.py` — новые регрессии;
- документация и контрольные суммы пакета.

Конфигурация источников, workflow, GOLD, архивы, секреты и параметры рассылки не
изменяются.

## Установка

Из корня репозитория:

```bash
unzip -o SE-monitor-update-80-run43-precision-recall-1.0.zip -d .
python -m pytest -q
```

Ожидаемый маркер сборки:

```text
2026-09-04.social.80-run43-precision-recall-1.0
```

Проверка файлов пакета:

```bash
sha256sum -c SHA256SUMS.txt
```

## После установки

Запустите один dry-run и пришлите `social-report` вместе с `social-debug`.
Проверяются новые классы жалоб, объединение аварии водоснабжения в Любани и
отсутствие побочных допусков через редакционный `SUMMARY`.

## Архитектурная граница

Update80 завершает очередную коррекцию первого, regex-слоя. Семантическая модель
не включается и не участвует в решениях. Контракт накопления материала для
будущего второго слоя сохранён в версии `1.0`.

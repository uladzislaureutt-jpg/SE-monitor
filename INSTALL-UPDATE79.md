# Установка update79

Пакет является корневым overlay для репозитория, в котором уже установлен
update78. Содержимое ZIP начинается от корня проекта: вложенную папку создавать
не нужно.

## Что будет заменено или добавлено

- `social_monitor.py` — системные фильтры точности/полноты, заголовки Telegram
  и консолидация дублей;
- `tests/test_update77_semantic_data_contract.py` — актуальный маркер сборки;
- `tests/test_update78_guarded_grievance_dedup.py` — актуальный маркер сборки;
- `tests/test_update79_run42_systemic_precision.py` — новые регрессии;
- документация и контрольные суммы пакета.

Конфигурация источников, workflow, GOLD, накопленные архивы и секреты не
изменяются.

## Установка

Из корня репозитория:

```bash
unzip -o SE-monitor-update-79-run42-systemic-precision-1.0.zip -d .
python -m pytest -q
```

Ожидаемый маркер в диагностике:

```text
2026-09-04.social.79-run42-systemic-precision-1.0
```

Проверка файлов пакета:

```bash
sha256sum -c SHA256SUMS.txt
```

## После установки

Запустите один dry-run. Для проверки результата достаточно прислать его
`social-report` и `social-debug`. В новом прогоне особенно проверяются три
возвращённых класса жалоб, четыре класса шума, объединение трёх публикаций о
Гомельской психиатрической больнице и полный заголовок Telegram с `Mak.by`.

## Архитектурная граница

Update79 улучшает первый, regex-слой. Он не включает модель и не заменяет
будущий семантический второй фильтр. Контракт семантического архива сохранён в
версии `1.0`, поэтому новые прогоны остаются совместимыми с подготовленным GOLD
и будущим сравнением компактных моделей Hugging Face.

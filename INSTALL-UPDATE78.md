# Установка update78

Пакет является корневым overlay для репозитория, в котором уже установлен
update77. Распаковывать вложенную папку целиком в репозиторий не нужно:
содержимое ZIP уже начинается от корня проекта.

## Что будет заменено или добавлено

- `social_monitor.py` — фильтры и консолидация дублей;
- `tests/test_update77_semantic_data_contract.py` — актуальный маркер сборки;
- `tests/test_update78_guarded_grievance_dedup.py` — новые регрессии;
- документация и контрольные суммы пакета.

Конфигурация источников, workflow, GOLD и накопленные архивы не изменяются.

## Установка

Из корня репозитория:

```bash
unzip -o SE-monitor-update-78-guarded-grievance-dedup-1.0.zip -d .
python -m pytest -q
```

Ожидаемый маркер в диагностике:

```text
2026-09-04.social.78-guarded-grievance-dedup-1.0
```

Проверка файлов пакета:

```bash
sha256sum -c SHA256SUMS.txt
```

## Архитектурная граница

Update78 усиливает первый, regex-слой. Он не обучает модель и не заменяет
будущий семантический второй фильтр. Контракт семантического архива update77
сохранен в версии `1.0`, поэтому накопленные тексты остаются пригодны для
последующего сравнения компактных моделей Hugging Face на зафиксированном GOLD.

# Социально-экономический мониторинг Беларуси

Рабочий репозиторий для ручного запуска мониторинга через GitHub Actions.
Подробная инструкция для нового владельца поставляется отдельным Word-файлом.

## Состав

- `.github/workflows/daily-social-monitor.yml` — единственный рабочий workflow;
- `social_monitor.py`, `main.py` — код мониторинга;
- `config/sources.csv` — 46 активных источников;
- `config/settings.yaml` — фильтры и параметры;
- `data/state.json`, `data/discovery_cache.json` — чистое начальное состояние;
- `tests/test_social_monitor.py` — актуальный регрессионный тест рабочего кода.

Исторические диагностические workflow, разовые скрипты проверки источников,
резервные списки и накопленное состояние прежнего владельца удалены.

## Необходимые GitHub Secrets

В `Settings` → `Secrets and variables` → `Actions` создайте:

1. `SMTP_USERNAME` — полный адрес Gmail, с которого отправляются отчёты;
2. `SMTP_PASSWORD` — 16-значный пароль приложения Google, а не пароль аккаунта;
3. `REPORT_TO` — адрес получателя отчётов (может совпадать с `SMTP_USERNAME`).

Адреса и пароли нельзя записывать в `settings.yaml`, workflow или другие файлы.

## Ручной запуск

1. Откройте вкладку `Actions`.
2. Выберите `Daily social monitor`.
3. Нажмите `Run workflow`.
4. Для первой проверки включите `dry_run`; затем выполните обычный запуск без него.

Первый обычный запуск создаёт исходную базу ссылок (warmup). Последующие запуски
обрабатывают новые публикации и отправляют отчёт по электронной почте.

Workflow сохраняет обновлённые `data/state.json` и
`data/discovery_cache.json` обратно в ветку `main`. Внешний cron не настроен:
запуск выполняется только вручную.

# Установка update77

Распакуйте содержимое архива **в корень репозитория** с заменой совпадающих
файлов. Структура архива уже соответствует корню: `social_monitor.py`,
`.github/`, `data/`, `ml/`, `tests/`.

Перед заменой рекомендуется создать ветку или commit. Затем выполните:

```bash
python -m pytest -q
```

Ожидаемая сборка после установки:
`2026-09-03.social.77-semantic-data-contract-1.0`, Core `3.6`.

После первого успешного не-dry-run запуска проверьте:

- в артефакте `social-debug-<run>` появился
  `semantic_training_signals_<date>.csv`;
- после сохранения state в репозитории появился файл
  `data/ml/raw_history/semantic_inputs/run-<N>_semantic_training_signals_<date>.csv`;
- обычный отчёт формируется без изменений структуры.

Не копируйте файлы из `semantic_inputs/` в публичные отчёты: они содержат
нормализованные фрагменты извлечённого текста.

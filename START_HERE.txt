НАЧНИТЕ С WORD-ИНСТРУКЦИИ, ПРИЛОЖЕННОЙ К АРХИВУ

Кратко:
1. Создайте новый приватный репозиторий GitHub без README, .gitignore и лицензии.
2. Распакуйте архив и загрузите содержимое папки S-monitor с сохранением структуры.
3. Создайте Secrets: SMTP_USERNAME, SMTP_PASSWORD, REPORT_TO.
4. В Actions запустите Daily social monitor сначала с dry_run, затем без dry_run.
5. Первый обычный запуск — инициализация базы ссылок; следующие — рабочие отчёты.
